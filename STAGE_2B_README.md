# Stage 2B free-data evidence gate (partial milestone)

Adds an unattended daily GitHub Actions assessment of **existing Neon product observations** and ranks research scenarios. It does not fetch new Amazon commercial data. No evidence of 12-month Amazon demand, accurate fees, sourcing, or resale eligibility exists in current free data; consequently no buy recommendations are generated. Keepa is a disabled future adapter with zero paid calls.

**Prerequisite:** `automated_research_report.py` from Stage 1 must already be committed. Reuses existing GitHub Actions `DATABASE_URL` secret.

Add the five files from this ZIP to the corresponding paths on `main`. Open Actions > Stage 2B commercial intelligence (free data, read-only) > Run workflow, then download the `stage-2b-commercial-assessment` artifact.

This is not final Stage 2B: authorized live commercial data collection, dashboard delivery, email delivery, and acceptance testing remain pending.
