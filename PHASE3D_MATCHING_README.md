# Phase 3.0D — Offline product matching
Add the four package files at their supplied paths. Requires the installed Phase 3.0C module and commercial_privacy.py. Run Phase 3.0D Product Matching Tests from main. The demo uses structured synthetic attributes and a hypothetical EUR/GBP conversion rate of 1.20 EUR per GBP. No live queries, persistence, purchase recommendations or activation. Matching requires equal valid GTIN, brand, model, variant, explicit pack count and NEW condition on both sides. A mismatch rejects; missing evidence requires review. Title equality alone cannot qualify. Invalid GTIN raises a fixed error. Price plus shipping is not landed cost and does not include taxes, duties, fees or FX costs. The input shipping quote must be explicitly selected for the intended destination by a future adapter. No live provider mapping, batch deduplication, historical demand, or production storage authorization is implemented. No credentials or Render changes. Production API collection and deletion gates remain closed.
